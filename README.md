# Job Portal

A full-stack Job Portal application that connects **candidates and recruiters** through a secure and role-based platform. Candidates can browse and apply for jobs, while recruiters can manage companies, create job postings, and manage applications.

## Tech Stack

### Backend

* Node.js
* Express.js
* Supabase
* PostgreSQL
* JWT Authentication
* REST APIs

### Frontend

* React
* Vite
* Tailwind CSS

## Key Features

* User registration and login
* JWT-based authentication
* Role-based access control
* Candidate profile management
* Recruiter/company management
* Job creation and job listing
* Job details
* Job applications
* Saved jobs
* Application status management
* Supabase Row Level Security (RLS)


## Security

* Supabase Authentication
* JWT token validation
* Role-based authorization
* Row Level Security (RLS)
* Centralized error handling
* Environment-based configuration
* Helmet security headers
